# Missão Aquário Digital

## Gestão e Qualidade de Software

Projeto desenvolvido para praticar o fluxo de versionamento e gestão de software utilizando Git e GitHub.

## Ambientes

- **develop**: ambiente utilizado para desenvolvimento e integração de novas funcionalidades.
- **stage**: ambiente utilizado para testes e homologação antes da liberação.
- **main**: ambiente de produção, contendo as funcionalidades já validadas e aprovadas.

## Módulo de Controle da Qualidade da Água

O módulo `ControleQualidadeAgua.java` monitora os níveis de pH e temperatura do aquário, emitindo alertas quando os parâmetros estão fora dos limites definidos.
